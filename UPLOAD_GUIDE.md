# Upload CareShield AI to GitHub

1. Unzip `careshield-ai.zip`.
2. On GitHub, create a new **public** repository named `careshield-ai`. Do **not** initialize it with a README.
3. Open the new repository and choose **uploading an existing file**.
4. Upload the files and folders from *inside* the unzipped `careshield-ai` directory, keeping `src/`, `tests/`, and `.streamlit/` paths intact. Some browsers skip hidden files; `.streamlit/config.toml` is optional for functionality.
5. Commit. Check that `app.py`, `README.md`, and `requirements.txt` appear in the repository root.
6. Run the commands in README on your MacBook to verify.

**Suggested repository description:** Context-aware healthcare access risk research lab using synthetic EHR audit logs, machine learning and interactive security analytics.

**Topics:** cybersecurity, healthcare-security, python, streamlit, machine-learning, insider-threat, synthetic-data, security-analytics

Do not describe the model as validated on real security incidents.
